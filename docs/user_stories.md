# User Stories – Blockchain Trade Settlement Prototype

## Clearing Risk Analyst

**Story 1**  
As a **clearing risk analyst**, I want to see each participant's netted cash and securities obligations so that I can identify firms with elevated settlement risk.

**Story 2**  
As a **clearing risk analyst**, I want to see the overall fail-to-settle rate so that I can monitor the effectiveness of the settlement process.

## Operations Analyst

**Story 3**  
As an **operations analyst**, I want every trade, netting action, and settlement result to be recorded on an immutable ledger so that I can audit the full lifecycle of any transaction.

**Story 4**  
As an **operations analyst**, I want to simulate T+1 settlement using realistic starting balances so that I can understand which participants are likely to fail and why.

## Product Manager – Digital Assets

**Story 5**  
As a **product manager for digital assets**, I want to compare gross vs net exposure so that I can quantify the benefits of netting in a tokenized settlement environment.

**Story 6**  
As a **product manager for digital assets**, I want to understand how a blockchain-inspired ledger could improve transparency and reconciliation so that I can design better workflows for institutional clients.

## Business Systems Analyst

**Story 7**  
As a **business systems analyst**, I want a clear set of functional requirements and process flows so that I can communicate system behavior to both technical and business stakeholders.

**Story 8**  
As a **business systems analyst**, I want the system to produce structured outputs (e.g., CSV/JSON metrics) so that downstream reporting and dashboards can be built by analytics teams.
